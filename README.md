# Clipper AI

A tiny, animated Windows paperclip companion with a voice generated by your choice of LLM.

**This is a fork of [toxic8yte/clipper](https://github.com/toxic8yte/clipper), maintained in [DNAshx/clipper](https://github.com/DNAshx/clipper).** The original desktop character, artwork, WPF animations, blinking, sleeping, dragging, and system tray behavior come from the upstream project. This fork replaces its canned reactions with LLM-generated speech and adds provider, model, credential, and prompt settings.

![Clipper](clipper/Assets/clipper_original.png)

## What changed in this fork

- **Three providers:** OpenAI (the models behind ChatGPT), Anthropic Claude, and Google Gemini, using their official APIs.
- **Bring your own API key:** separate credentials and model selections for each provider, saved with Windows DPAPI encryption for the current Windows user.
- **Model selection:** a compact, fast model selected by default for each provider, plus an editable model ID for other models available to your account.
- **Live model catalogs:** models load automatically when a key is entered or saved-key settings are opened. The original presets remain available when offline or if the catalog request fails. **Обновить модели** refreshes the list manually without changing your selected model.
- **Claude workspace support:** organization-wide keys automatically use the workspace when exactly one is available. An optional Workspace ID field supports accounts with multiple workspaces.
- **Generated speech throughout:** greeting, left-click reaction, “Say something,” waking up, optional application-change reactions, and “What do I notice?” All character dialogue comes from the selected LLM. There is no canned dialogue fallback.
- **Left click:** the paperclip playfully acknowledges being touched and asks what you want. Click and drag still moves the character.
- **Editable prompts:** customize the character's personality and all six event prompts in the settings window.
- **Language selection:** Russian by default; English, Spanish, or a language you type yourself.
- **Optional context:** sharing the foreground application name and window title is off by default, as are automatic application reactions.
- **Responsive networking:** asynchronous requests, cancellation, a 25-second timeout, a short click cooldown, and longer background cooldowns.
- **English documentation and Windows CI:** build, offline checks, and a downloadable self-contained Windows x64 build artifact.

## Requirements

- Windows 10 or Windows 11.
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) to build from source.
- An API key and API access/quota for at least one supported provider.
- Internet access when generating speech.

The settings and context menus currently use Russian labels. The speech language is configurable independently.

## Build and run

```powershell
git clone https://github.com/DNAshx/clipper.git
cd clipper
dotnet build clipper.slnx -c Release
dotnet run --project clipper/clipper.csproj -c Release
```

On first launch, the LLM settings window opens automatically.

1. Select **OpenAI**, **Anthropic**, or **Gemini**.
2. Paste your provider's API key into the masked API-key field. **Получить API-ключ** opens the provider's key page.
3. The app loads the provider's text models using your key. Keep the recommended model, choose a loaded model or preset, or enter an exact API model ID. The built-in list stays available throughout.
4. Choose the speech language. Optionally customize the prompts under **Промпты**.
5. Click **Проверить подключение** to generate a test greeting with the current draft settings. This makes one real API request and may incur a charge.
6. Click **Сохранить** to save. **Отмена** discards unsaved changes. **Удалить ключ** clears the selected provider's key after you save.

These are direct provider **API-key connections**. Subscription sign-in/OAuth for ChatGPT, Claude, or Gemini is not implemented in this version; use the provider's API credentials.

### Claude connection troubleshooting

Some Anthropic keys can access multiple workspaces and require the `anthropic-workspace-id` header. Clipper detects this error, looks up accessible workspaces, and retries with the sole available workspace. If there are several, enter your intended `wrkspc_...` ID in **Claude Workspace ID**. Keys already scoped to a workspace can leave this field empty. Save settings to keep the resolved ID.

Loading the model catalog confirms API access but does not prove that generation has sufficient credits. Clipper reports insufficient API balance separately from invalid keys, missing workspace selection, and rate limits. Check **Plans & Billing** in your [Claude Console](https://platform.claude.com/) if the API reports a low credit balance.

The workspace behavior follows the [Anthropic workspace documentation](https://platform.claude.com/docs/en/manage-claude/workspaces). Provider catalogs use the official [OpenAI Models API](https://developers.openai.com/api/reference/resources/models/methods/list), [Claude Models API](https://platform.claude.com/docs/en/api/models/list), and [Gemini Models API](https://ai.google.dev/api/models). Model-list requests do not generate speech; connection tests do.

## Recommended models

| Provider | Default API model | Rationale |
| --- | --- | --- |
| OpenAI | `gpt-6-luna` | Efficient model for focused tasks; reasoning is disabled for short replies. |
| Anthropic | `claude-haiku-4-5` | Anthropic's fast, compact Claude option. |
| Google | `gemini-3.5-flash-lite` | Low latency and low cost; minimal thinking for quick speech. |

The defaults were checked against the [OpenAI model documentation](https://developers.openai.com/api/docs/models/gpt-6-luna), [Claude model catalog](https://platform.claude.com/docs/en/models/overview), and [Gemini model documentation](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite) on October 6, 2026. Availability and actual latency depend on your provider account and service conditions. Enter a custom ID when a provider updates its catalog.

## Controls

| Action | Behavior |
| --- | --- |
| Left click on the character | Generate a playful “you poked me” reply and a question about what you want. |
| Click and drag | Move the character without generating a click reply. |
| Right click → **Сказать что-нибудь** | Generate a fresh, short remark. |
| Right click → **Что я сейчас вижу?** | Generate a comment on the last observed external application; requires context sharing. |
| Right click → **Настройки LLM и промпты…** | Open provider, model, language, privacy, and prompt settings. |
| Right click → **Вернуться в угол** | Return to the bottom-right corner. |
| Right click → **Спрятаться в трей** | Hide and cancel pending speech. |
| Tray double click | Show the character again. |
| Tray menu → **Настройки LLM и промпты…** | Configure the app even while the character is hidden. |
| Menu → **Выйти** | Exit the application. |

The character sleeps after three minutes of inactivity and wakes when you resume input. Repeated clicks do not create a request queue. Explicit user actions take priority over background requests. Automatic application reactions have a 45-second global cooldown and a two-minute cooldown per process, including failed attempts.

## Personality and prompts

The default character is warm, curious, and gently witty, with self-deprecating office humor. Replies are limited to one or two short sentences and at most 180 characters, without formatting. The last five generated lines are included in subsequent requests to discourage repetition; they stay in memory and are cleared when settings change or the app exits.

The **“Say something”** prompt is:

> The user selected 'Say something'. Surprise them with one delightful little remark: a paperclip's observation, gentle office absurdity, tiny encouragement, or playful question. Use the suggested theme only as inspiration. Do not assume what the user is doing. Prefer an original conversational line over a generic productivity reminder.

A randomly selected theme adds variety without embedding prewritten dialogue. The left-click prompt asks the model to acknowledge the poke, sound amused and curious, and ask what the user wants. Edit these prompts and the shared system prompt in the app; **Восстановить стандартные промпты** restores defaults in the draft until you save.

## Data and credentials

Settings are stored at `%LOCALAPPDATA%\ClipperAI\settings.dat`. The entire file, including keys and prompts, is encrypted using Windows DPAPI with `CurrentUser` scope. It is tied to your Windows account and should not be copied between users. Reset settings by closing Clipper and removing that file.

API requests go directly to the selected provider. They contain your configured prompts, chosen language, event description, and up to five recent character replies. OpenAI requests set `store: false`. When context sharing is enabled, requests can also contain the foreground process name and up to 160 characters of its window title. Titles may include document names, chat names, or other private information. No screenshots, file contents, executable paths, or clipboard contents are sent.

Context sharing and automatic application reactions are separate switches, both off by default. Automatic application reactions require both switches to be enabled. Status labels such as loading, missing credentials, and connection errors are ordinary application UI and are kept separate from generated character dialogue. If generation fails, the app reports the error instead of inventing a fallback reply.

## Checks

The dependency-free Windows test runner uses fake HTTP responses and does not need API keys or call paid services:

```powershell
dotnet run --project tests/Clipper.Tests -c Release
```

It checks provider endpoints/authentication/payloads, response parsing, hidden thinking blocks, error sanitization, cancellation, reply length, context privacy, encrypted settings round trips, corrupt-settings recovery, and settings-window provider switching. It does not validate live provider availability or generated reply quality. Use the in-app connection test for your own account.

The tests also cover model-catalog pagination, text-model filtering, fallback presets, preserved selections, stale responses, workspace auto-resolution, and separate billing errors. To explicitly diagnose Claude with your current Windows user's encrypted key, run `dotnet run --project tests/Clipper.Tests -c Release -- --check-claude`. This opt-in command loads the real model list and makes one short generation request that may incur an API charge; it never prints credentials or generated content. Normal test runs remain offline.

## Publish a portable Windows build

```powershell
dotnet publish clipper/clipper.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/ClipperAI-win-x64
```

Run `artifacts/ClipperAI-win-x64/clipper.exe`. Keep its **Assets** folder alongside the executable. The build includes the .NET runtime, so the target machine does not need a separate .NET installation. The GitHub Actions workflow produces the same application folder as the `ClipperAI-win-x64` artifact.
